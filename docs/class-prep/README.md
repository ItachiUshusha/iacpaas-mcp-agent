# Подготовка к практическому занятию

Основная работа к паре — разобраться с выданной онтологией и инфоресурсом и показать прототип.

Начните с этих файлов:

1. [Предметный разбор](01_Разбор_онтологии_и_базы.md) — реальные понятия и данные, связь двух уровней, пример плотности и найденная неполнота.
2. [Текст выступления](02_Текст_выступления.md) — что говорить за 6–8 минут и короткая версия на две минуты.
3. [План показа](03_План_показа_и_команды.md) — окна, команды, ожидаемые результаты и запасной сценарий без сети.

`collect-materials.ps1` выполняет один вход, читает реальные фрагменты и при доступном окружении проверяет ресурсы через MCP. Живое выполнение подтверждено 21 октября: три ресурса, depth=3 через API, по 6 успешных вызовов MCP через каждый транспорт. См. [результат проверки](04_Результат_живой_проверки.md).

`demo-current.ps1` запускает уже отработанный сценарий системы единиц через актуальный код, без необходимости вручную искать Python. По умолчанию режим live; `--mode snapshot` — проверка на сохранённом корне.

Изучены не все ресурсы фонда, а конкретная пара и показанный фрагмент. Предметный разбор основан на просмотрщике и дополнен реальными ограниченными экспортами. Работа с настоящей LLM ещё не демонстрировалась.
