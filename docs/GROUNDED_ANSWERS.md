# Ответы с проверяемыми источниками

Исходный ответ о газах опирался на фрагмент «Базы свойств материалов» глубиной 2
(32 вершины, 31 связь) и поиск по названиям четырёх ресурсов.
Это не поиск по содержимому и не доказательство отсутствия данных во всём фонде.
live_api означает живой API, а не сохранённый снимок.

## Что добавлено

- search_inforesource: поиск внутри universal-экспорта по name/value/meta/link/comment.
  Запрос — одно слово или основа: водород, аргон, примес.
  Результат содержит путь по дереву, поля узла, первые 20 потомков, JSON Pointer,
  evidence_id и хеш экспорта.
- compare_node_children: пересечение меток непосредственных потомков двух выбранных узлов.
  Для вопроса о примесях нужны именно два списка примесей соответствующих газов.
  Результат содержит исходные записи с обеих сторон каждого совпадения.
- Статус цитирования в веб-чате: ссылки существуют, отсутствуют или выдуманы.
  Нажатие на [E...] раскрывает ресурс, путь, источник, глубину и исходные поля.
- Статистика переименована в «Прочитанный фрагмент» и отделена от обоснования ответа.

Проверяется существование ссылки в успешном результате инструмента.
Это **не независимая семантическая проверка всего текста LLM**:
реальную запись тоже можно неверно истолковать.
Число прочитанных вершин не доказывает предметный вывод.
В Cline доступны те же MCP-данные и evidence_id, но веб-проверка цитирования там не выполняется.

## Ограничения

Поиск: depth=0..10, ответ API до 2 МБ, обход до 20000 узлов, выдача до 30 совпадений и 128 КБ.
Старые методы сохраняют depth=0..3 и max_nodes=200.
JSON Pointer относится к экспорту и не является параметром start API.
При изменении экспорта сравнение отклоняется с EXPORT_CHANGED.
Ссылки не разворачиваются; пустой/нераскрытый список даёт INSUFFICIENT_DATA.
Синонимы и формулы автоматически не объединяются.
Отсутствие совпадений в ограниченном экспорте не доказывает отсутствия сведений во всём фонде.

## Запуск

Перезапустите MCP и веб-чат, обновите страницу Ctrl+F5 и начните новый диалог.
Работающие процессы продолжают использовать старый код.

    .\run.ps1 serve --transport http --mode live --login

В другом терминале используйте прежнюю команду web с выбранной моделью и
--mcp-url http://127.0.0.1:8765/mcp.

Проверочный запрос для доступных баз:
«Найди внутри подключённых ресурсов записи водорода и аргона. Покажи исходные поля
и ссылки на записи. Не считай химический элемент списком примесей газа».

Для базы с газами, когда она будет подключена:
«Найди списки примесей газов на основе водорода и аргона, вычисли пересечение
через compare_node_children и укажи источники с обеих сторон».

Для проверки и подключения нового ресурса укажите его точный относительный путь
из «Моего Фонда». Например, если база находится в «Загрузках»:

    .\run.ps1 study --resource-path 'Загрузки/База технологических газов' --depth 10

Команда сохраняет экспорт в локальной папке `data/` и добавляет в каталог только
ресурс с подтверждёнными названием и кодом. После подключения перезапустите MCP.
