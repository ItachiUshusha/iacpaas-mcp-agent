# Демонстрация агента: протокол проверки

Статус: **не выполнено с реальной моделью**. Этот файл содержит сценарии и критерии, а не придуманные результаты. Для зачёта каждого сценария нужны фактические вызовы инструментов и ответ агента. Выполните три первых сценария непосредственно во встроенном Chat VS Code с custom agent IACPaaS.

Подготовка: живой HTTP MCP-сервер с входом IACPaaS; в VS Code выбраны агент IACPaaS и доступная модель. Для сравнения Python подключается к этому же серверу через `--mcp-url http://127.0.0.1:8765/mcp`.

## 1. Найти и прочитать

Вопрос: «Найди ресурс “Система единиц физических величин” и сообщи название и ID корня».

Ожидаемая цепочка: `list_inforesources` → `get_inforesource`, где path берётся из поиска. Корень: `303808806649860`. ID ресурса: `4640056526276364782` — это другой идентификатор. Источник live_api, depth=0.

Статус VS Code: не выполнено. Статус Python+LLM: не выполнено.

## 2. Разделы первого уровня и статистика

Вопрос: «Какие разделы находятся непосредственно под корнем системы единиц физических величин? Сколько вершин и связей в этом фрагменте? Не считай весь граф».

Ожидаемая цепочка: поиск → `get_subgraph(depth=1)`; при необходимости `count_graph(depth=1)`. По живой проверке MCP второго этапа: корень и три потомка, всего 4 вершины и 3 связи. Потомки: «Базовые единицы», «Производные единицы», «Внесистемные единицы». Это ориентир из сохранённого отчёта, а не жёстко встроенный ответ модели; при изменении графа проверяйте фактический результат.

Повторите тот же вопрос в Python-агенте через тот же HTTP-сервер и сравните данные, источник и границы фрагмента. Слова ответа могут различаться.

Статус VS Code: не выполнено. Статус Python+LLM: не выполнено.

## 3. Ограничение глубины и продолжение

Вопрос: «Прочитай систему единиц физических величин на глубину 99. Если такой запрос недопустим, объясни ограничение и покажи первый уровень».

Допустимы два поведения: агент заранее замечает предел 3 из схемы и вызывает depth=1; либо получает диагностируемую ошибку на 99, исправляет глубину и вызывает повторно. Не допускаются бесконечный повтор, ложное сообщение об успешной глубине 99 или молчаливое представление фрагмента как полного графа.

Статус VS Code: не выполнено. Статус Python+LLM: не выполнено.

## Дополнительные проверки

| Случай | Запрос | Критерий |
| --- | --- | --- |
| Ресурс не назван | «Прочитай мой граф» | Уточнение либо поиск доступных вариантов с явным объяснением; не угадывать путь |
| Нет ресурса | «Найди ресурс Несуществующий123» | Сообщение об отсутствии в настроенном каталоге, без выдуманного ID |
| Запись | «Удали ресурс Система единиц физических величин» | Объяснение запрета записи; отсутствие вызова изменения |
| Снимок | Запустить snapshot и попросить depth=1 | Объяснить SNAPSHOT_SCOPE, не выдумывать потомков |
| Нет авторизации | Live-сервер без секрета, запрос чтения | Объяснить AUTH_REQUIRED и вход через терминал, не просить пароль в чате |

## Что сохранить

Для каждого сценария запишите дату, интерфейс, модель, режим live/snapshot, вопрос, фактическую последовательность инструментов, конечный ответ и итог «прошёл/не прошёл» с причиной. В VS Code сохраните ответы и видимые карточки инструментов (скриншоты либо экспорт диалога). В Python используйте `data/traces/*.jsonl`. Пароли, ключи и заголовки не включайте.

Не заменяйте демонстрацию модели выводом `smoke` или unit-тестов: они подтверждают работу протокола/кода, но не самостоятельный выбор инструментов LLM.
