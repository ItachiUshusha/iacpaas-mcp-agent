# IACPaaS MCP Agent

**Обновление 26 октября:** добавлены локальный веб-чат, совместимый облачный API (включая бесплатный `openrouter/free`) и конфигурация Cline для VS Code. [Запуск модели, веба и IDE](docs/FREE_MODEL_AND_WEB.md). Прошли 32 теста. Веб поддерживает форматирование ответов, карточки данных MCP, историю, прокрутку и кнопку «В конец».

Учебный проект по инженерии знаний: MCP-сервер для чтения графов IACPaaS и агент, который использует его инструменты. Основной предметный пример — онтология и база свойств материалов. Система единиц используется также для технических проверок на снимке.

**Готово:** живой MCP проверен по stdio и Streamable HTTP; реализованы Python-агент и веб-чат. Есть пользовательский запуск агента на сохранённом корне. **Ещё не подтверждено:** полный сценарий LLM + живые материалы и три сценария в IDE. Конфигурация Cline подготовлена, установка и подключение расширения выполняются отдельно.

## Возможности и статус

| Возможность | Статус |
| --- | --- |
| Вход IACPaaS и экспорт universal JSON | Проверено на реальной платформе |
| MCP stdio / Streamable HTTP с общей доменной логикой | Проверены оба транспорта |
| Схемы аргументов и результатов, ограничения, ошибки | Реализовано, покрыто тестами |
| Корень и подграф depth=1 | Проверено на живом API |
| Python-агент: диалог, tool calling, трасса | Реализовано; тесты с подменённой моделью |
| Адаптеры OpenAI Responses / Ollama / совместимый Chat Completions API | Реализованы; ключи задаются при запуске |
| Веб-чат | Реализован; в браузере проверены оформление, прокрутка и вывод инструментов |
| Custom agent и MCP-конфигурация VS Code | Подготовлены; демонстрации ещё впереди |
| Изменение графов | Запрещено политикой; инструменты записи отсутствуют |

## Архитектура

```text
VS Code custom agent / Cline ──────┐
Python CLI → LLM → tool calls ─────┼─ MCP stdio / Streamable HTTP
Веб-чат → Python-агент → LLM ──────┘       → server.py → domain.py
                                              → iacpaas_client.py → IACPaaS
```

`smoke.py` выполняет заранее заданный сценарий без LLM. В CLI и вебе инструменты выбирает подключённая модель, вызовы исполняет `agent_core.py`. В Cline цикл агента управляется расширением. MCP API общий для всех интерфейсов.

## Быстрый запуск на Windows

Нужен Python 3.10+; проверенная среда — Python 3.12. Из корня репозитория в PowerShell:

```powershell
.\setup.ps1
.\run.ps1 test
.\run.ps1 smoke
```

Установка создаёт `.venv` и использует закреплённые зависимости `requirements-lock.txt`. Скрипт выбирает установленный Python Codex, если он есть, иначе системный Python. Для установки пакетов нужна сеть.

По умолчанию проверка использует сохранённый корень без входа:

```text
OK: stdio, snapshot, 7 tool calls
OK: http, snapshot, 7 tool calls
```

Для живого API нужен аккаунт IACPaaS с доступом к ресурсу из `catalog.json`:

```powershell
.\run.ps1 smoke --mode live
```

Вход выполняется в терминале, пароль скрыт. Альтернатива — одна переменная окружения `IACPAAS_TOKEN` или `IACPAAS_API_KEY`. Значения секретов не включаются в исходники и аргументы команд.

## Веб-чат и облачная модель

Создайте API-ключ выбранного провайдера. Для OpenRouter:

```powershell
.\run.ps1 web --provider compatible --model openrouter/free --ask-key
```

Ключ вводится скрыто в терминале. Откройте `http://127.0.0.1:8080`. По умолчанию используется snapshot с корнем системы единиц; для материалов нужен живой режим.

Чтобы веб и VS Code использовали один сервер, сначала запустите HTTP MCP с входом командой из следующего раздела. Затем во втором терминале:

```powershell
.\run.ps1 web --provider compatible --model openrouter/free --ask-key --mcp-url http://127.0.0.1:8765/mcp
```

История диалога находится в памяти, трассы — в исключённой из Git папке `data/traces/`. Под ответом видны фактические вызовы инструментов. Карточки чисел строятся из успешных MCP-результатов. Форматирование поддерживает основной набор Markdown; HTML модели выводится как текст. Для обновления интерфейса используйте Ctrl+F5.

`openrouter/free` выбирает бесплатную модель с нужными возможностями; доступны ограничения квоты и временные отказы провайдера. Код для OpenRouter ограничивает цену входных и выходных токенов нулём. Сменить совместимый сервис можно через `--base-url` или `AI_BASE_URL`; тариф другого сервиса определяется его провайдером.

## MCP-сервер

Локальный HTTP с входом:

```powershell
.\run.ps1 serve --transport http --mode live --login
```

Адрес: `http://127.0.0.1:8765/mcp`. Сервер работает, пока открыт терминал; остановка — Ctrl+C. `.vscode/mcp.json` использует этот адрес. Сервер предназначен для локальной однопользовательской работы; авторизация удалённых клиентов не реализована.

Stdio на сохранённом корне:

```powershell
.\run.ps1 serve --transport stdio --mode snapshot
```

Stdio — протокольный канал для запуска клиентом; обычного приглашения в терминале не будет. Для live-stdio секрет передаётся в окружении запускающего клиента.

## Инструменты

| MCP tool | Реализация |
| --- | --- |
| `list_inforesources` | Поиск по настроенному `catalog.json`, без перечисления всего фонда |
| `get_inforesource` | GET `/api/data/export/user-item`, universal, depth=0 |
| `get_subgraph` | Экспорт с глубиной и необязательным `start-target-concept-path` |
| `count_graph` | Ограниченный экспорт и локальный подсчёт описаний вершин, ссылок и связей |

Каталог содержит систему единиц, базу свойств материалов, её онтологию и онтологию описания характеристик и их значений. 21 октября для трёх ресурсов материалов подтверждены корни и фрагменты depth=3 через API, а также по 6 успешных вызовов MCP через stdio и HTTP. Для другого аккаунта укажите доступный ему ресурс с точными `path`, `title`, `resource_id`. Отсутствие в каталоге не означает отсутствия ресурса на платформе.

Статистика относится к возвращённому фрагменту и может включать предков. Ссылки не разворачиваются; число описаний не выдаётся за точный размер полного графа. При depth=0 сохранённый корень даёт одну вершину и ноль связей.

## Агент и VS Code

Актуальный запуск веба и Cline: [docs/FREE_MODEL_AND_WEB.md](docs/FREE_MODEL_AND_WEB.md). Первоначальная инструкция встроенного Chat: [docs/AGENT_SETUP.md](docs/AGENT_SETUP.md).

```powershell
.\run.ps1 agent --provider compatible --model openrouter/free --mode live
# Или другой провайдер:
.\run.ps1 agent --provider openai --model MODEL_ID --mode live
# Или локальный Ollama:
.\run.ps1 agent --provider ollama --model MODEL_ID --mode live
```

`MODEL_ID` заменяется точным именем доступной модели с tool calling. Совместимый API использует `AI_API_KEY`, `AI_MODEL`, `AI_BASE_URL`; OpenAI — `OPENAI_API_KEY`, `OPENAI_MODEL`. Ключи можно вводить скрыто в терминале. Модели не устанавливаются автоматически; привязки к модели преподавателя нет.

В VS Code откройте корень репозитория, запустите HTTP-сервер, проверьте `iacpaas` через `MCP: List Servers` и выберите custom agent **IACPaaS** во встроенном Chat. Доступ к модели проверяется отдельно.

Для чата Cline установите расширение, выберите провайдера и модель, затем добавьте сервер из `config/cline-mcp.json` в настройки MCP Cline. Это отдельная конфигурация: Cline не подхватывает `.vscode/mcp.json` автоматически. Не заменяйте другие настроенные серверы при добавлении записи.

## Проверки и доказательства

Прошли 32 теста: 13 доменных, 11 агентных/провайдерных, 4 предметных и 4 проверки совместимого API и веба. Проверяются обнаружение пути до чтения, продолжение tool calling, нулевая цена маршрутизации OpenRouter, история и сброс веб-диалога, ошибки конфигурации и доступа. Агентные тесты используют настоящий MCP stdio/HTTP и явно подменённую модель; веб-тест выполняет цепочку через настоящий MCP stdio. Качество реальной LLM автоматические тесты не подтверждают.

- Живой MCP материалов, 21 октября 2026: по 6 вызовов stdio/HTTP; первый уровень базы — 6 вершин и 5 связей. [Сводка запуска](evidence/verification-materials-live.json). Полный отчёт хранится локально в `data/`.
- [Живой MCP, 18 октября 2026](evidence/verification-live.json): по 7 вызовов через каждый транспорт; первый уровень — 4 вершины и 3 связи.
- [Проверка на снимке](evidence/verification-snapshot.json): корень, статистика и ожидаемые ошибки.
- [Сценарии для настоящей модели](DEMO_SCENARIOS.md): пока не отмечены выполненными.

Новые отчёты и трассы пишутся в `data/`, исключённую из Git. `fixtures/root.json` — сохранённый реальный корень с удалёнными полями персонального пути и владельца. Он не подтверждает текущий доступ к API.

## Ограничения текущей версии

- MCP: depth=0..3, максимум 200 описаний вершин, граф до 128 КБ, ответ платформы до 2 МБ, таймаут 40 секунд.
- Snapshot: только корень, без потомков и `start`.
- Непустой `start` ещё не проверен на живом API. Для материалов через API проверены depth=0 и 3, в MCP-сценарии — depth=0 и 1; полный граф не выгружался.
- Полная официальная JSON Schema IACPaaS и проверка онтологии не реализованы.
- Выполнен первоначальный [разбор онтологии и базы свойств материалов](docs/MATERIALS_STUDY.md) по просмотрщику: пять классов, пример плотности, ограничения отношений и обнаруженная неполнота. Остальные выданные ресурсы подробно не изучены.
- Полный прогон реальной LLM на живых материалах и три сценария VS Code ещё нужно подтвердить. Веб предназначен для локальной однопользовательской работы на loopback; публичное размещение с авторизацией не реализовано.
