# IACPaaS MCP Agent

Учебный проект по инженерии знаний: MCP-сервер для чтения графов IACPaaS и агент, который использует его инструменты.

**Готово:** чтение настоящего ресурса через MCP проверено по stdio и Streamable HTTP. Код Python-агента и конфигурация VS Code подготовлены. **Ещё не проверено:** запуск с настоящей языковой моделью и три демонстрации в IDE. Это рабочий промежуточный результат учебного проекта.

## Возможности и статус

| Возможность | Статус |
| --- | --- |
| Вход IACPaaS и экспорт universal JSON | Проверено на реальной платформе |
| MCP stdio / Streamable HTTP с общей доменной логикой | Проверены оба транспорта |
| Схемы аргументов и результатов, ограничения, ошибки | Реализовано, покрыто тестами |
| Корень и подграф depth=1 | Проверено на живом API |
| Python-агент: диалог, tool calling, трасса | Реализовано; тесты с подменённой моделью |
| Адаптеры OpenAI Responses / локальный Ollama | Реализованы; реальные модели пока не проверены |
| Custom agent и MCP-конфигурация VS Code | Подготовлены; демонстрации ещё впереди |
| Изменение графов | Запрещено политикой; инструменты записи отсутствуют |

## Архитектура

```text
VS Code custom agent ─────────────┐
                                 ├─ MCP stdio / Streamable HTTP
Python CLI → LLM → tool calls ────┘       → server.py → domain.py
                                              → iacpaas_client.py → IACPaaS
```

`smoke.py` выполняет заранее заданный сценарий без LLM. В `agent.py` инструменты выбирает подключённая модель. Один MCP API используется обоими интерфейсами.

## Быстрый запуск на Windows

Нужен Python 3.10+; проверенная среда — Python 3.12. Из корня репозитория в PowerShell:

```powershell
.\setup.ps1
.\run.ps1 test
.\run.ps1 smoke
```

Установка создаёт `.venv` и использует закреплённые зависимости `requirements-lock.txt`. Скрипт выбирает установленный Python Codex, если он есть, иначе системный Python. Для установки пакетов нужна сеть.

По умолчанию проверка использует сохранённый корень без входа:

```text
OK: stdio, snapshot, 7 tool calls
OK: http, snapshot, 7 tool calls
```

Для живого API нужен аккаунт IACPaaS с доступом к ресурсу из `catalog.json`:

```powershell
.\run.ps1 smoke --mode live
```

Вход выполняется в терминале, пароль скрыт. Альтернатива — одна переменная окружения `IACPAAS_TOKEN` или `IACPAAS_API_KEY`. Значения секретов не включаются в исходники и аргументы команд.

## MCP-сервер

Локальный HTTP с входом:

```powershell
.\run.ps1 serve --transport http --mode live --login
```

Адрес: `http://127.0.0.1:8765/mcp`. Сервер работает, пока открыт терминал; остановка — Ctrl+C. `.vscode/mcp.json` использует этот адрес. Сервер предназначен для локальной однопользовательской работы; авторизация удалённых клиентов не реализована.

Stdio на сохранённом корне:

```powershell
.\run.ps1 serve --transport stdio --mode snapshot
```

Stdio — протокольный канал для запуска клиентом; обычного приглашения в терминале не будет. Для live-stdio секрет передаётся в окружении запускающего клиента.

## Инструменты

| MCP tool | Реализация |
| --- | --- |
| `list_inforesources` | Поиск по настроенному `catalog.json`, без перечисления всего фонда |
| `get_inforesource` | GET `/api/data/export/user-item`, universal, depth=0 |
| `get_subgraph` | Экспорт с глубиной и необязательным `start-target-concept-path` |
| `count_graph` | Ограниченный экспорт и локальный подсчёт описаний вершин, ссылок и связей |

Каталог содержит систему единиц, базу свойств материалов, её онтологию и онтологию описания характеристик и их значений. 21 октября для трёх ресурсов материалов подтверждены корни и фрагменты depth=3 через API, а также по 6 успешных вызовов MCP через stdio и HTTP. Для другого аккаунта укажите доступный ему ресурс с точными `path`, `title`, `resource_id`. Отсутствие в каталоге не означает отсутствия ресурса на платформе.

Статистика относится к возвращённому фрагменту и может включать предков. Ссылки не разворачиваются; число описаний не выдаётся за точный размер полного графа. При depth=0 сохранённый корень даёт одну вершину и ноль связей.

## Агент и VS Code

Подробная инструкция: [docs/AGENT_SETUP.md](docs/AGENT_SETUP.md).

```powershell
.\run.ps1 agent --provider openai --model MODEL_ID --mode live
# Или локальный Ollama:
.\run.ps1 agent --provider ollama --model MODEL_ID --mode live
```

`MODEL_ID` заменяется точным именем доступной модели с tool calling. OpenAI-ключ берётся из `OPENAI_API_KEY` либо скрытого ввода в терминале. Модели не устанавливаются автоматически. Доступ к Qwen преподавателя пока не настроен: параметры сервера неизвестны.

В VS Code откройте корень репозитория, запустите HTTP-сервер, проверьте `iacpaas` через `MCP: List Servers` и выберите custom agent **IACPaaS** во встроенном Chat. Доступ к модели проверяется отдельно.

## Проверки и доказательства

Ранее прошли 23 теста: 13 доменных и 10 агентных/провайдерных. Для подготовки предметного разбора добавлены ещё 4 теста: поля онтологии, безопасная регистрация ресурсов, отказ при недоступном экспорте и корректная ошибка при отсутствии снимка материалов. Агентные тесты включают настоящий MCP stdio/HTTP с явно подменённой моделью. Они проверяют цепочки, исправление аргументов, ограничения и запрет записи; качество реальной LLM ими не подтверждается.

- Живой MCP материалов, 21 октября 2026: по 6 вызовов stdio/HTTP; первый уровень базы — 6 вершин и 5 связей. [Сводка запуска](evidence/verification-materials-live.json). Полный отчёт хранится локально в `data/`.
- [Живой MCP, 18 октября 2026](evidence/verification-live.json): по 7 вызовов через каждый транспорт; первый уровень — 4 вершины и 3 связи.
- [Проверка на снимке](evidence/verification-snapshot.json): корень, статистика и ожидаемые ошибки.
- [Сценарии для настоящей модели](DEMO_SCENARIOS.md): пока не отмечены выполненными.

Новые отчёты и трассы пишутся в `data/`, исключённую из Git. `fixtures/root.json` — сохранённый реальный корень с удалёнными полями персонального пути и владельца. Он не подтверждает текущий доступ к API.

## Ограничения текущей версии

- MCP: depth=0..3, максимум 200 описаний вершин, граф до 128 КБ, ответ платформы до 2 МБ, таймаут 40 секунд.
- Snapshot: только корень, без потомков и `start`.
- Непустой `start` ещё не проверен на живом API. Для материалов через API проверены depth=0 и 3, в MCP-сценарии — depth=0 и 1; полный граф не выгружался.
- Полная официальная JSON Schema IACPaaS и проверка онтологии не реализованы.
- Выполнен первоначальный [разбор онтологии и базы свойств материалов](docs/MATERIALS_STUDY.md) по просмотрщику: пять классов, пример плотности, ограничения отношений и обнаруженная неполнота. Остальные выданные ресурсы подробно не изучены.
- Запуск с реальной LLM и три демонстрации VS Code остаются следующими шагами.
